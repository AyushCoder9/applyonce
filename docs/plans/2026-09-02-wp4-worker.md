# WP4 — background worker (apps/worker)

Scope: `apps/worker/**` only. No deps/lockfile changes.

## Files
- `src/logger.ts` — pino (pretty in dev)
- `src/s3.ts` — S3 client (path-style, MinIO), putObject/getObject/presignGet
- `src/handlers/verification.ts` — digilocker.sync, pan.verify, aa.income, abha.link
- `src/handlers/documents.ts` — document.process (AV stub + OCR → extractions)
- `src/handlers/webhooks.ts` — webhook.deliver (HMAC POST, retry via throw)
- `src/handlers/notifications.ts` — notify (insert + prefs + sms/email) + `notifyUser()` helper reused by other handlers
- `src/handlers/scheduled.ts` — scan.expiries / scan.mismatches / scan.handover18 / scan.deadlines + `registerSchedulers()`
- `src/handlers/data.ts` — data.export, data.erase
- `src/handlers/index.ts` — `handlers: Record<JobName, (data)=>Promise<unknown>>`
- `src/inline.ts` — `runInline`, registers `globalThis.__applyonceInlineJobs`
- `src/index.ts` — boot: one `Worker` per queue (concurrency 5, webhooks 10), routes by `job.name`, registers schedulers, 60s queue-count health log, graceful shutdown
